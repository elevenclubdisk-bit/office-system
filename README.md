# ระบบทะเบียนครุภัณฑ์และระบบยืม-คืนวัสดุสำนักงาน

โครงสร้างไฟล์
- `index.html`  โครงหน้าเว็บ (HTML)
- `css/style.css`  รูปแบบและการพิมพ์ (CSS)
- `js/app.js`  ตรรกะทั้งหมด (JavaScript)

วิธีใช้
1. เปิด `index.html` ด้วย Chrome/Edge/Firefox (ต้องออนไลน์เพื่อโหลด Bootstrap, Font Awesome, SheetJS จาก CDN)
2. เปิดครั้งแรกจะให้สร้างบัญชีผู้ดูแลระบบ (ไม่มีรหัสผ่านเริ่มต้น)
3. ข้อมูลเก็บในเบราว์เซอร์เครื่องนี้ ควรกด "สำรองข้อมูล" เป็นประจำ

ใช้งานจริง/ออฟไลน์: ดาวน์โหลด Bootstrap, Font Awesome, SheetJS มาไว้ในโฟลเดอร์ `vendor/`
แล้วแก้ลิงก์ใน `index.html` และ CSP (meta) ให้ชี้ไปที่ไฟล์ในเครื่อง
หากเปิดผ่านเว็บเซิร์ฟเวอร์ควรใช้ HTTPS เพื่อให้ใช้ Web Crypto ได้เต็มประสิทธิภาพ
